# How to use?
1. Create workflow here - [https://cua-app-v2-henna.vercel.app/dashboard](https://cua-app-v2-henna.vercel.app/dashboard)
2. Connect a self hosted runner - `npx --yes github:che-codes-01/cua-runner --service-url https://cua-service.vercel.app --api-key cak_live_<key>`
3. Use the recorder to record the workflow - ` npx --yes github:che-codes-01/cua-recorder`
4. Import the saved workflow -> Publish -> select runner on which this workflow needs to be executed -> execute.
